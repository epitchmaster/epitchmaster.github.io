เติม eFootball Coin

ผ่าน eFootball™ Web Store ที่ดำเนินการโดย Coda (Codashop) ผู้ขายที่ได้รับอนุญาต

  1. ผูกบัญชี eFootball กับ KONAMI ID ในเกมก่อน
  2. เปิดร้าน เลือกประเทศ แล้วล็อกอินด้วย KONAMI ID ที่ผูกกับเกม
  3. ตรวจบัญชี จำนวน Coin และราคาให้ถูกก่อนจ่ายทุกครั้ง
